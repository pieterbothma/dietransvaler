# Afrikaanse styl — Die Transvaler

Die reël: **die gehoor se oor wen oor die woordeboek.** Wat volg is nie
voorskriftelik nie — dit is die korreksies wat Piet werklik gemaak het, sodat
dieselfde foute nie herhaal word nie.

## Woordkeuses wat reggemaak is

| Nie dit nie | Maar dit | Waarom |
|---|---|---|
| sjabloon | raamwerk | lees Nederlands |
| voorpak | aanpak | "voorpak" is nie 'n woord in dié konstruksie nie |
| geblokkeer | geblok | korter, en dis wat mense sê |
| vergesel van | vergesel met | |
| eggenote | eggenoot | die vroulike -e-vorm lees gedateer |
| in die swart getrek | in die groen gestoot | SA finansiële idioom, nie 'n vertaling nie |
| by die naam | by naam | vaste uitdrukking; "by die naam" verwag 'n naam daarna |
| statisch | staties | Nederlandse indringer |
| werf (vir 'n webwerf) | webwerf | "werf" alleen is 'n plaaswerf |
| die aanhalings is gesê | die aanhalings is gemaak | |
| so vinnig ons kan | so vinnig as wat ons kan | die vergelykende partikel ontbreek |
| vier ure | vier uur | ná 'n telwoord bly "uur" enkelvoud |
| hamster (as werkwoord) | opgaar / oppot | Nederlandse leenwoord |

## Sinsbou

- **Voegwoord "dat" nie weglaat nie.** Nie "kondig aan beurtkrag is nou…" nie,
  maar "kondig aan **dat** beurtkrag nou … **is**". Dieselfde met "waarsku dat
  … kan duur". Sonder "dat" is dit 'n Engelse kalkering.
- **Tydsbepaling voor die werkwoordstuk**, infinitief heel laaste: "om
  **Vrydag** vir die All Blacks **te kook**", nie "…te kook Vrydag" nie.
- **Behoorlike dubbele ontkenning** waar dit hoort.

## Leestekens

- `’n` met die regte aanhalingsteken (U+2019), nooit `‘n` nie.
- Meervoud met apostroof: `foto's`, nie `fotos` nie.
- Komma binne die aanhaling voor die toeskrywing: `"Dis 'n saak van beginsel,"
  het hy gesê.`
- Samestellings word vasgeskryf: `personeelvergadering`, `plastiekstrooitjies`,
  `OnlyFans-rekening` (koppelteken by 'n eienaam).

## Afkortings

Moenie 'n afkorting invoer wat nie werklik gebruik word nie. "Sapo" is
verwyder — skryf eerder "die Poskantoor" deurgaans.

## Register

Die humor sit in die inhoud, nooit in die aanbieding nie. Geen uitroeptekens in
die koerant se eie stem nie (in 'n aanhaling is dit reg). Geen knipoog vir die
leser nie. Hoe erniger die toon, hoe snaakser die berig.
